# Regridder API Reference

::: xregrid.Regridder

The `Regridder` is the main class for performing regridding operations in XRegrid. It provides an optimized interface to ESMF (Earth System Modeling Framework) for interpolating data between different grids.

## Overview

A `Regridder` instance is created by providing a source grid and a target grid. Once initialized, the regridder can be called directly on an `xarray.DataArray` or `xarray.Dataset` to perform the regridding.

```python
from xregrid import Regridder

# Create regridder
regridder = Regridder(ds_src, ds_tgt, method='bilinear')

# Apply to DataArray
regridded_data = regridder(ds_src.variable)

# Apply to entire Dataset
regridded_ds = regridder(ds_src)
```

## Key Methods

### __call__

::: xregrid.Regridder.__call__

Apply regridding to an input DataArray or Dataset.

### diagnostics

::: xregrid.Regridder.diagnostics

Generate spatial diagnostics of the regridding weights, such as the sum of weights and unmapped cell masks.

### quality_report

::: xregrid.Regridder.quality_report

Generate a scientific quality report containing metrics like unmapped point counts and weight statistics.

### persist

::: xregrid.Regridder.persist

Ensure that weight generation tasks are submitted to the Dask cluster.

### compute

::: xregrid.Regridder.compute

Trigger computation and assembly of weights if they are being generated in parallel.

## Visualization Methods

XRegrid implements a **Two-Track Rule** for visualization:
- **`mode='static'` (Track A)**: Publication-quality plots using Matplotlib and Cartopy.
- **`mode='interactive'` (Track B)**: Exploratory plots using HvPlot and HoloViews.

### plot_comparison

::: xregrid.Regridder.plot_comparison

Unified comparison plot showing the source grid, target grid, and the difference.

### plot_diagnostics

::: xregrid.Regridder.plot_diagnostics

Visualize the spatial diagnostics generated by the `diagnostics()` method.

### plot_weights

::: xregrid.Regridder.plot_weights

Visualize the source points that contribute to a specific destination point.

## Serialization

### from_weights

::: xregrid.Regridder.from_weights

Create a `Regridder` instance from a pre-computed weights file.

### weights_to_xarray

::: xregrid.Regridder.weights_to_xarray

Export the regridding weights as an xarray Dataset for analysis or manual saving.
